# 🏥 Emergency Room Analytics Dashboard

A Power BI dashboard analyzing 9,216 emergency room patient records from April 2023 to October 2024. This project provides insights into patient wait times, satisfaction scores, department referrals, demographics, peak busy periods, and admission patterns.

## 📊 Key Insights

- 👥 Total Patients: 9,216
- ⏱️ Average Wait Time: 35.3 minutes
- ⭐ Average Satisfaction Score: 4.99 / 10
- 🏥 Top Referral Department: General Practice
- 📅 Busiest Day: Monday
- 👨‍👩‍👧‍👦 Largest Age Group: 30–39 years
- 🚑 Admission Split: Nearly 50% admitted and 50% treated & released
